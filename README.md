# Dự Án Website Khởi Đầu: Đặc Sản Tây Nguyên

Dự án môn học xây dựng phiên bản khởi đầu (trọng tâm vào kiến trúc, cấu trúc dữ liệu, tổ chức dự án và quy trình cộng tác) cho website giới thiệu và phân loại đặc sản Tây Nguyên.

---

## 1. Cấu Trúc Thư Mục Dự Án (Repository Structure)

```text
tay-nguyen-specialties/
├── index.html              # Trang chủ (Danh sách sản phẩm, lọc, định hướng đặt hàng)
├── about.html              # Trang giới thiệu chi tiết về Tây Nguyên
├── contact.html            # Trang liên hệ
├── css/
│   └── style.css           # File định dạng giao diện chung
├── data/
    └── main.js
│   └── products.json       # Tập tin chứa dữ liệu 10+ đặc sản
└── README.md               # Tài liệu dự án, phân công & nhật ký tiến độ
```
